Is VaLight Tracker Safe?

Yes, absolutely. VaLight Tracker strictly abides by Riot Games third-party application policies. It never touches game files or memory.

Audit the Source Code on GitHub
  • Official Local Loopback API
    Queries the read-only HTTP endpoints exposed locally by the official Riot Client on your machine (127.0.0.1).
  • Zero DLL Injection or Memory Hooks
    Never hooks into Valorant's process memory, never bypasses Vanguard, and never modifies game assets.
  • No Riot Logins or Passwords
    Authenticates locally via the temporary session lockfile created by the Riot Client. Your credentials are never seen or stored.

Got Questions?

Frequently Asked Questions

Can I get banned by Riot Vanguard for using this?
No. VaLight Tracker uses the official Riot Client loopback API on your PC to fetch match stats. It does not inject DLLs, read game memory, or modify files. It operates 100% out-of-process, exactly like Discord or streaming tools.
Will it affect my in-game FPS?
Not at all. Unlike heavy Overwolf or Chromium-based apps that consume 1 GB+ of RAM, VaLight Tracker uses a Rust-powered Tauri shell taking ~40 MB of RAM and near-zero CPU. Your game performance will remain identical.
Do I need to sign into my Riot account?
No. As long as the official Riot Client is running on your computer, VaLight automatically detects your active session via the local lockfile. You never enter a username, password, or 2FA code.
How do updates work?
Every time you open the app, it checks GitHub for new releases. If a newer version exists, a sleek notification card appears showing the release notes and an "Update Now" button. Clicking it downloads and updates the app in seconds.
What happens if Windows Defender shows SmartScreen?
Because VaLight Tracker is a newly released, open-source project without a $500/year corporate code-signing certificate, Windows SmartScreen may show "Windows protected your PC". Click More info and then Run anyway. You can inspect all source code on GitHub anytime.
